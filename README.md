# 🎬 MyCinema — Aether Cinema Web Platform

A high-performance cinematic streaming platform built with **React**, **Vite**, and customized cyber-luxury aesthetics. Features multi-audio streams, verified servers, Hindi dubbing support, age clearance gates, and live web extraction.

---

## ✨ Features

- **⚡ Top 4 Verified Playable Streaming Nodes**:
  - **Server 1 (VidLink Pro)**: 4K UHD, normalized stereo vocals, multi-track audio.
  - **Server 2 (VidSrc PM)**: 1080p Full HD with direct Hindi Dub (`ds_lang=hi`) & dual audio.
  - **Server 3 (AnyEmbed VIP)**: Low latency, high gain, fast cloud streaming.
  - **Server 4 (2Embed Prime)**: Global CDN mirror failover node.
- **🇮🇳 Multi-Audio & Hindi Dubbing**: 1-click audio track switching and automatic routing to Hindi dub mirrors for Marvel/Hollywood sagas.
- **🛡️ Age Advisory & Verification Protocol**: 13+ / 18+ content maturity screening with local device persistence.
- **🔐 Authentication & Local Session Persistence**: Sign in / register without relogin prompt on same device until manual logout.
- **🔊 Dialogue & Vocal Clarity Booster**: 3-step audio normalization guide with instant high-gain server switches.
- **🌐 Live Web Extractor & Custom TMDB Player**: On-the-fly metadata scraper and player for any TMDB/IMDb movie or series.
- **🎨 Cyber-Luxury Aesthetic**: Responsive glassmorphism, gold neon accents, fluid carousel reels, and cinema-grade dark mode.

## 🚀 Getting Started

### Prerequisites
- Node.js (v18 or higher recommended)
- npm or yarn

### Installation
```bash
# Clone repository
git clone https://github.com/div2006-creator/MyCinema.git

# Navigate to project directory
cd MyCinema

# Install dependencies
npm install
```

### Running Locally
```bash
npm run dev
```
Open `http://localhost:5173` in your browser.

### Building for Production
```bash
npm run build
```
